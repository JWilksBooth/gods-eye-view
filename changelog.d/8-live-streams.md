- Live Streams: a `streams` layer and `/api/streams` provider put geotagged
  public live cameras on the map for Los Angeles, Sonoma County, the San
  Francisco Bay Area and Las Vegas. A curated registry (every YouTube entry
  verified through oEmbed, Caltrans HLS playlists verified live) serves
  keyless; `YOUTUBE_API_KEY` adds YouTube Data API discovery under a daily
  budget with an hourly per-region cache, `WINDY_WEBCAMS_API_KEY` adds Windy
  webcams, and Broadcastify scanner directories link out. Streams join the
  event map as `stream` icons whose click opens the feed drawer, so nothing
  loads until a stream is opened; `find_live_streams` joins the MCP and voice
  tools (JWilksBooth, #8).
